## 📱 Responsive Behavior

### Desktop (> 768px)
- 3-column grid for main cards
- Side-by-side strategy leaders
- Multi-column risk dashboard
- Horizontal button groups

### Tablet (≈ 768px)
- 2-column grid where possible
- Stacked strategy leaders
- 2-column risk items
- Wrapped button groups

### Mobile (< 768px)
- Single column layout
- Full-width cards
- Vertical button stacking
- Larger touch targets

### Button States
```
Normal:  [Button Text]           ← Base color
Hover:   [Button Text]           ← Darker shade
Active:  [Button Text]           ← Even darker
Disabled: [Button Text]          ← Gray, not clickable
```

### Card Hover Effects
```
Normal:
┌──────────┐
│  Card    │
└──────────┘

┌──────────┐  ← Lifts up 5px

### Filter Button States
```
Inactive: [Last Hour]  ← White background, purple border

## 🎨 Design Principles

### 1. **Visual Hierarchy**
- Most important info (Portfolio Performance) has gradient background
- Top strategies get medal rankings
- Critical alerts use warning banners

### 2. **Consistency**
- Same card style throughout
- Consistent color coding
- Uniform spacing and padding

### 3. **Clarity**
- Clear labels for all metrics
- Color-coded positive/negative values
- Status indicators easy to understand

### 4. **Interactivity**
- Hover effects on clickable elements
- Smooth transitions
- Visual feedback on actions

### 5. **Responsiveness**
- Mobile-first approach
- Flexible grid layouts
- Touch-friendly buttons

---

## 🚀 Visual Performance

### Optimization
- CSS transitions instead of JavaScript
- SVG icons where possible
- Minimal image usage
- Efficient grid layouts

### Loading States
- Spinner animation while loading
- Skeleton screens (could be added)
- Smooth data transitions
